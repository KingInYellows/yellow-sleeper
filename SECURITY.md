# Security

This repository does **not** currently enable GitHub private vulnerability reporting, and there is **no** published security contact.

Do not assume a private intake path exists. Do not invent one.

If you believe you found a vulnerability in this code:

- Do not include live league ids, usernames, credentials, or exploit payloads in a public issue.
- You may open a public GitHub issue that describes impact at a high level, or wait until the owner publishes a contact.

Operator cache files and `.yellow-sleeper.yaml` can contain league identity. They are gitignored on purpose.

Sleeper and FantasyCalc terms apply to data this server caches. See the data-rights section in `README.md`.
